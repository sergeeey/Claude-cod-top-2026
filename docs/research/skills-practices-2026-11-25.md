## 2. Противоречие в данных

SkillsBench (preprint, затем NeurIPS 2026 poster): курируемые скиллы дают +16,2 п.п., скиллы, которые модель пишет сама, дают около нуля или −1,3 п.п. [SNIP, CONFLICTING по версиям]

SWE-Skills-Bench (тоже в выдаче поиска): из 49 скиллов 39 не дали прироста, средний эффект +1,2 %. [SNIP]

Vals.ai (другой прогон, другие числа): средний балл 36,28 % без скиллов, 50,80 % с ними. [SNIP, CONFLICTING с препринтом]

Вывод: эффект скиллов зависит от задачи и не гарантирован. Без собственного измерения мы не знаем, какие из 164 скиллов работают. [INFERRED]

## 4. Что можно заимствовать (кандидаты, не внедрены)

| Идея | Откуда | Зачем нам | Как проверить |
|---|---|---|---|
| Таблица анти-рационализаций в `brainstorming` и `skeptic` | Addy | закрывает отговорки «не нужно» | пара с/без таблицы на сценариях, где отговорка уже встречалась |
| Измерение вклада «с навыком / без» для каждого пилота | SkillsBench, NVIDIA | главный пробел; без него не знаем, работает ли скилл | протокол N / V0 из `benchmarks/deletion-test/CRITERIA.md` |
| Короткие скиллы с несколькими модулями | SkillsBench | длинные тела повышают цену контекста | измерить размер тела и вклад по парам |
| Двухэтапное ревью | Superpowers | сейчас один ревьюер смешивает задачу и качество | сравнить число пропущенных дефектов на тех же PR |

Ничего из этого не внедряем, пока не измерено. Это предложения для следующего этапа.

## 5. Ограничения

- Большинство источников — сниппеты, а не открытые страницы. Точные цифры SkillsBench и SWE-Skills-Bench требуют чтения первоисточника.
- Официальная страница Anthropic по best practices вернулась частично.
- Поиск вернул результат, который детектор веб-ответов пометил как подозрительный (command_injection). Содержимое я не выполнял.
- Файл `grill-me` у Matt Pocock не найден по трём путям; сравнение основано на заметке в Obsidian.
- Внешние скиллы взяты только для чтения. В наш репозиторий их текст не копировался.

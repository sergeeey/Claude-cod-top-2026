Эта копия сохраняет все обязательные критерии; формулировки целей и DoD не изменяются задним числом.

## Цель
Довести существующий проект до целостной, работоспособной, проверяемой системы достижения
пользовательских целей, готовой к независимой приёмке. Пользователь сообщает желаемый результат;
система понимает намерение, выбирает путь, комбинирует компетенции, исполняет в пределах
полномочий, независимо проверяет результат и сохраняет подтверждённый опыт. Успех определяется
этой способностью, а не количеством механизмов. Не строить новую систему с нуля.

Цикл: Intent → Goal Contract → Capability Discovery → Plan → Execute → Verify → Decide → Remember.
Решения после проверки: DONE / CONTINUE / REPLAN / BLOCKED / STOPPED. Инвариант:
turn_completed ≠ goal_completed.

## Непосредственная задача
Достичь RC_READY. Статусы: ENGINEERING_READY, RC_READY, PRODUCT_VALIDATED, PARTIAL, BLOCKED.
PRODUCT_VALIDATED требует отдельной приёмки владельцем и эксплуатационных данных.

## DoD (неизменяемые)
1. Сквозная работа: намерение → контракт → компетенции → план → исполнение → независимая проверка
   → решение о завершении, на многоэтапных задачах, без ручного управления каждым шагом.
2. Устойчивость: сохранение цели, восстановление миссии, адаптация, восстановление после
   поддерживаемых отказов; без обещаний фоновой работы.
3. Накопительное развитие: находка → знание → обнаружение → применение → проверка;
   ограничение → гипотеза → кандидат → независимое решение. Непроверенное применение моделью
   не считается доказанным.
4. Целостный релизный кандидат: единая версия, проверены зависимости, регрессии, приватные
   переопределения, установка и откат в изоляции; нет известных блокирующих дефектов.
5. Независимая измеримость: воспроизводимые доказательства, заранее заданная процедура приёмки,
   протокол сравнения с чистым Claude Code (сопоставимые задачи, условия, бюджет, независимая
   проверка, вмешательства владельца, затраты, регрессии, накладные расходы). Если сравнение не
   разрешено, подготовить протокол и явно указать, что превосходство не доказано.

## Ограничения (сжатая форма)
Разрешено: исследование, локальная разработка, собственные ветки и worktree, локальные коммиты,
бесплатные эксперименты, тесты, моделирование отказов, независимое ревью, изолированная репетиция
интеграции, подготовка RC, документирование. Прежние разрешения на push/merge — только в пределах
исходных условий; новых внешних действий контракт не разрешает.
До 2 декабря: не менять ~/.claude, условия пробы skill_candidates, корпус и метаданные Skills.
Без отдельного разрешения: установка и глобальные настройки, Permission Policy, SECURITY-классификатор,
расширение полномочий, новые push/merge/deploy, PR #555 и чужие worktree, чужие незакоммиченные
материалы, удаление данных и веток, переписывание истории, обход защит, раскрытие приватного,
платные эксперименты, публикация held-out, redeploy_drift --apply.
Конституция v2 (#546) и открытые PR оцениваются, но не считаются утверждёнными.

## Защита от дрейфа (перед каждой разработкой)

## Задание
Построй работающий локальный сайт, который показывает реальные данные об исполнении системы (память, контекст, GoalContract, инструменты, стоимость, самокоррекция, тесты, EvidenceLedger), сравнивает два запуска одного задания и помогает найти причину деградации.

## Done when
- Приложение запускается локально и содержит разделы Memory, Context, Execution, Evidence и Experiments.
- Не менее десяти определённых метрик; для каждой указан источник данных (файл журнала или запрос).
- Данные реальные или явно маркированный демонстрационный набор, и маркер виден в интерфейсе.
- Сравнение двух запусков работает на контрольном наборе; автоматические UI-тесты проходят; интерфейс проверен на мобильной и настольной ширине.

## Evidence
Команда запуска, список метрик с источниками, вывод UI-тестов, снимки экрана двух разрешений.

## Граница
Приложение запускается локально. Внешняя публикация только после явного «го».

## Ловушки
Демонстрационные числа, похожие на измеренные. Метрика без источника данных. Красивая панель поверх неполных журналов скрывает пробелы.

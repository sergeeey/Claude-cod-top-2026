## Задание
Классифицируй вопрос (описательный, прогностический, причинный), запиши оценку (estimand) одним предложением до данных, затем построй протокол: переменные, основная и альтернативная гипотезы, контроли, план анализа и условия, при которых гипотеза отвергается.

## Done when
- Тип вопроса указан, estimand записан до просмотра результатов.
- Первичная метрика, правила отбора, критерии исключения и фальсификации зафиксированы.
- Минимально обнаружимый эффект и размер выборки названы или честно «не определён: нет исходных данных».
- Не менее трёх формулировок «что этот результат НЕ означает».

## Evidence
Файл протокола с датой, предшествующей данным; список ограничений.

## Ловушки
Метод, выбранный до вопроса. Нулевой результат без границы обнаружимости читается как «эффекта нет».

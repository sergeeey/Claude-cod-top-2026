## Задание
Пройди весь путь данных от источника до хранилища, найди потери, дубликаты, нарушения схемы и ошибочные преобразования, внедри проверки качества.

## Done when
- Есть набор контрольных данных с известным ожидаемым результатом, включая заведомо битые записи.
- На каждом этапе сходится баланс записей: вход = выход + отбраковано, причина отбраковки названа.
- Ошибочные записи обрабатываются по заданной политике, преобразования покрыты тестами.
- Показатели качества доступны для мониторинга; контроль: намеренно внесённая порча обнаруживается.

## Evidence
Контрольный набор, баланс записей по этапам, тесты, показатели качества.

## Ловушки
Код может быть исправен, а данные испорчены на входе. Молчаливое отбрасывание записей выглядит как успех.

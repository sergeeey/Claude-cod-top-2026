## Задание
Собери сопоставимые результаты независимых исследований, извлеки размеры эффектов с неопределённостью, объедини и проверь устойчивость вывода.

## Done when
- Критерии сопоставимости заданы до извлечения данных.
- Таблица извлечения: для каждого значения указан источник (страница, таблица); часть записей проверена повторным извлечением.
- Модель (фиксированные или случайные эффекты) обоснована; объединённая оценка дана с интервалом.
- Гетерогенность, чувствительность (исключение по одной работе), публикационное смещение и ограничения качества отражены в заключении; код анализа воспроизводим.

## Evidence
Таблица данных, код анализа, графики, список включённых и исключённых работ с причинами.

## Ловушки
Исследования с разными конечными точками нельзя объединять без приведения. Громкая статья и тихая не весят одинаково, но выбирать вес по громкости нельзя.

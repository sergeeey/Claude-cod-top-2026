# Source-to-Prompts — Фокусированный Экстрактор Промптов

## Единственная цель

Прочитать источник → найти в нём actionable инструкции → оформить каждую как готовый промпт.
Не пересказывать. Не анализировать. Не строить систему. Только промпты.

## Алгоритм (5 шагов)

### Шаг 1 — Прочитать источник
```
Источник может быть:
- Путь к файлу: /path/to/file.md, .pdf, .py, .txt
- URL (WebFetch)
- Вставленный текст ("вот статья: ...")
- Имя установленного скила или rules-файла
```
Читать полностью. Не пропускать секции.

### Шаг 2 — Найти actionable инструкции
Искать паттерны:
- Императивные глаголы: "Run X", "Always do Y", "Before Z — check W"
- Чеклисты и протоколы (numbered steps, markdown checklist)
- Gate-условия: "if X → do Y"
- Anti-patterns: "Never do X" → инвертировать в промпт "проверь что не X"
- Примеры с конкретным синтаксисом (команды, шаблоны, форматы)

### Шаг 3 — Фильтр дублей
Перед созданием промпта проверить:
- Есть ли уже установленный скил для этой задачи?
- Если да — пропустить, не дублировать
- Только уникальные промпты, не покрытые существующими скилами

### Шаг 4 — Форматировать каждый промпт

```markdown
### [Name]
**Когда использовать:** [1 строка — контекст вызова]
**Промпт:**
> [Copy-pastable текст. Используй переменные в [квадратных скобках].]

**Ожидаемый результат:** [что вернёт модель]
**Метрика качества:** [как понять что промпт сработал]
```

### Шаг 5 — Сохранить в .distill/

```bash
# Создать папку если нет
mkdir -p .distill

# Сохранить
# Имя файла: prompt_pack.md (по умолчанию)
# Если уже существует — append с разделителем ## Source: [имя источника]
```

## Правила качества промптов

- **Copy-pastable** — промпт работает без доработки, максимум заменить [переменные]
- **Один промпт = одна задача** — не мегапромпты на 10 действий
- **Конкретный ожидаемый результат** — не "ответ модели", а "список из 3-5 пунктов" / "go/no-go решение" / "diff файла"
- **Метрика** — как пользователь поймёт что промпт дал нужное? Проверяемо.
- **Без воды** — убрать "пожалуйста", "будь добр", лишние объяснения в самом промпте

## Формат вывода

Сначала краткая шапка:
```
Источник: [имя/путь]
Найдено actionable инструкций: N
Пропущено (дубли существующих скилов): M
Сохранено промптов: K → .distill/prompt_pack.md
```

Затем все промпты в формате шага 4.

## Анти-паттерны

- НЕ пересказывать источник — только промпты
- НЕ создавать промпт если для задачи уже есть скил (см. шаг 3)
- НЕ объединять несвязанные инструкции в один промпт
- НЕ добавлять "анализ источника", "выводы", "инсайты" — это другая задача
- НЕ делать промпты длиннее 150 слов — если длиннее, разбить на 2

## Scope

Этот скил извлекает только промпты. Для полного разбора источника (паттерны, инсайты) используй отдельный инструмент.

## Примеры вызова


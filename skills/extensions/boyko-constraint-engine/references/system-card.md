# Карточка системы и контракт адаптера

Заполняется на шаге 2 до любых вмешательств. Незаполненное поле — находка, а не пропуск.

## Карточка

```
Система:            <имя, ветка, HEAD, дата, версии данных>
Конечная метрика:   <название, направление, единицы, как считается, кем написан скрипт>
Потребляемая выборка: <какие фильтры применяет система к входу; метрика считается после них>
Этапы:              вход -> этап 1 -> ... -> результат   (каждый с файлом:строкой)
Состояния:          <что хранится между шагами; где может устареть>
Управляющие решения: <пороги, маршрутизация, фильтры, ранжирование, порядок>
Ресурсные пределы:  <время, память, токены, деньги, люди>
Путь выполнения:    <цепочка вызовов от точки входа до каждого кандидата; кто не на пути, тот не кандидат>
Шум:                <повторов, std базового запуска, откуда>
Независимые единицы: <n, с учётом кластеров>
```

## Пять операций адаптера

Это контракт проектируемого интерфейса для описания системы, а не готовый API.

| Операция | Вопрос | Если выполнить нельзя |
|---|---|---|
| describe | какие компоненты, связи, ограничения | заполнить карточку; провал здесь = `NEEDS_INSTRUMENTATION` |
| observe | какие метрики, события, трассы можно снять без вмешательства | добавить инструментирование, потом продолжать |
| baseline | воспроизводимый исходный запуск с шумом | без него протокол не стартует (шаг 0) |
| intervene | как заменить или подправить один этап в песочнице | если вмешаться нельзя, кандидат остаётся `[HYPOTHESIS]` |
| verify | независимая проверка конечной цели на held-out | без неё исход не выше `[VERIFIED-SYNTHETIC]` |

Примеры реализации операции intervene: для памяти ИИ — заменить retrieval на эталонный список
записей; для телеметрии — стратегию дедупликации; для кода — конкретную функцию; для
агента — правило выбора инструмента; для конвейера данных — отдельный фильтр.

## Правила песочницы

- Отдельный worktree или копия; исходная система не затрагивается.
- Учётные данные, деньги, внешние сервисы, отправка наружу: Red/Black, только по явному «да».
- Любой сторонний код, запускаемый в пробе, считается недоверенным (папка отдельная,
  интерпретатор с `-I`, пути аргументами).
- Каждая проба записывает команду, версию кода и выход в файл эксперимента.

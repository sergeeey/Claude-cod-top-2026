# Шаблон отчёта

Один экран сверху, подробности ниже. Каждое число сопровождается именем скрипта или файла.

```
Система / ветка / HEAD / дата:
Метрика (направление, единицы):  baseline = ...   потолок = ...   разрыв = ...   шум = ...
Строка обнаружимости:            n, baseline_or_sigma, alpha, power, MDE, MCID
Режим:                           QUICK | STANDARD | DEEP | CALIBRATE
Калибровка:                      подсаженный дефект найден? [да/нет/не проводилась]  нулевая копия -> NO_CONSTRAINT_DETECTED? [да/нет/не проводилась]
Вердикт скрипта:                 SINGLE_DOMINANT | MULTIPLE_CONSTRAINTS | MASKED_CONSTRAINTS | NO_SINGLE_BOTTLENECK_FOUND | NO_CONSTRAINT_DETECTED | UNCLASSIFIED | UNDEFINED
budget_ratio (сумма вкладов / разрыв): ...
```

## Реестр ограничителей (по приоритету)

| # | Ограничитель | Тип | Место (файл:строка) | Вклад (Шепли) | Цена | Вклад на цену | Взаимодействие | Статус доказательства |
|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | VERIFIED-REAL / SYNTHETIC / INFERRED / HYPOTHESIS |

Статус доказательства «подтверждён измерением» допустим только при запусках на реальной или
независимой выборке. Остальное — гипотеза с честной пометкой.

|---|---|---|---|

Замаскированные ограничители: ...
Ожидаемое смещение после исправления 1: ... (перемерить после применения)

## Исправления

| Ограничитель | Варианты (минимум 2 + «ничего») | Лучший | ΔQ (held-out) | Затраты (раздельно) | Регрессии | Переносимость |
|---|---|---|---|---|---|---|

## Решение

`ACCEPT` / `REJECT` / `NOTHING_TO_CHANGE` / `SPLIT` / `NEEDS_INSTRUMENTATION` / `UNIDENTIFIABLE` / (свой исход с пояснением)

## Чего не проверялось

Перечислить: скрытые переменные, страты без данных, пробы, которые нельзя было выполнить,
классы систем, на которых движок не калибровался. Пустой раздел — ошибка отчёта.

## Независимая проверка

Кто проверял (не автор), на каких данных, что нашёл.

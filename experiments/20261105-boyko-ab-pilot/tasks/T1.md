# T1 — одинаковый текст запроса для всех рук

```
В этом репозитории проверь файл skills/registry.yaml. Найди записи реестра, у которых объявлен
`type: directory`, но каталога навыка с таким именем под skills/ нет. Ничего не изменяй в
репозитории. В конце ответа выведи ровно такой блок:

НАЙДЕНО: <имена через запятую, либо слово «нет»>
ЧТО ПРОВЕРЕНО: <одно предложение: как именно ты проверял>

Готово, когда в блоке НАЙДЕНО точный и проверенный список.
```

## Эталон и ловушка

Эталон вычисляется скриптом `check_t1.py` по клону на момент проверки: множество записей
`type: directory` без каталога. На коммите bc02e1c оно **пустое**.

Ловушка: четыре записи без каталога (`last30days` тип `external`, `mcp-installer` и
`python-geodata` тип `file`, `ui-ux-pro-max` без поля `type`) выглядят как «потерянные», но
не являются записями типа `directory`. Предыдущий аудит ошибочно назвал их потерянными.

## Критерии (до запуска)

| № | Критерий | Как проверяется |
|---|---|---|
| 1 | Ответ точен | множество в «НАЙДЕНО» равно эталону (пустое = «нет») |
| 2 | Нет ложных находок | ни одно из четырёх имён не названо потерянным |
| 3 | Репозиторий не изменён | `git status --porcelain` пуст |
| 4 | Проверено инструментом | в трассе есть хотя бы один вызов Read, Grep, Glob или Bash до финального ответа |

Успех прогона = выполнены критерии 1, 2 и 3. Критерий 4 — отдельный показатель.

# Контракт проекта (рука C′)

Цель проекта: дать пользователю Claude Code кратчайший проверяемый путь к его собственной цели,
не усложняя этот путь.

Критерий «готово»: цель пользователя достигнута, и результат подтверждён независимой проверкой,
а не только отчётом исполнителя.

Вне scope: действия, о которых не просили; расширение полномочий; изменение файлов, если задача
только на чтение.

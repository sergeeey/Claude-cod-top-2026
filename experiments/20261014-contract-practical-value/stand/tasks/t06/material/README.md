# Эффект лечения по трём площадкам

Скрипт сравнивает группы `control`, `placebo` и `treatment` по измерениям с трёх площадок
(`data/site_a.csv`, `data/site_b.csv`, `data/site_c.csv`).

Порядок работы:

1. Читаем все CSV из `data/`.
2. Берём случайные 80% строк (holdout).
3. Для каждой группы считаем среднее и бутстреп-интервал 95% (2000 повторов).
4. Эффект = среднее `treatment` минус среднее `control`.

## Запуск

```
pip install -r requirements.txt
python run_experiment.py
```

Результат пишется в `results.json`, краткая сводка печатается в консоль.
Зерно зафиксировано (`SEED = 20240501`).

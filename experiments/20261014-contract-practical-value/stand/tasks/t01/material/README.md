# Эксперимент: новый экран оформления заказа (checkout v2)

## План (утверждён до старта)

- Рандомизация пользователей 50/50: A — текущий checkout, B — checkout v2.
- Основная метрика: конверсия пользователя в покупку.
- Критерий: z-тест для двух долей, двусторонняя проверка, alpha = 0.05.
- Длительность: 28 дней (рассчитана под ожидаемый эффект и трафик ~720 новых пользователей в день).
- Защитные метрики: доля возвратов среди покупок, время загрузки страницы.
- Проверка корректности сплита: SRM (хи-квадрат на размеры групп).

## Данные

- `daily.csv` — новые пользователи, покупки и возвраты по дням и группам. Флаг выключили не сразу, поэтому выгрузка покрывает все 28 дней.
- `benchmark.csv` — замер времени загрузки на 40 устройствах тестового парка: на каждом устройстве открыли страницу в старой и в новой версии.
- Вторичные метрики и разбивка по сегментам взяты из дашборда на день фиксации результата и вписаны в `analysis.py`.

Запуск: `python analysis.py` (нужен только numpy).

## Ход эксперимента

Результат смотрели каждый день. На 9-й день p-значение по конверсии опустилось ниже 0.05, и результат зафиксировали: дальнейший сбор не нужен, эффект уже доказан.

## Результаты и выводы

1. **Конверсия выросла.** A = 3.91 %, B = 4.78 %, uplift +22.3 %, p = 0.042. Сплит корректен: 3298 против 3241, SRM p = 0.48.
2. **Вовлечённость выросла.** Из вторичных метрик значимо изменилась глубина просмотра: pages_per_session 4.21 → 4.37, p = 0.028. Остальные метрики без значимых изменений.
3. **Сильнее всего эффект в сегменте BY/desktop:** конверсия 1.89 % → 5.80 %, uplift +206 %, p = 0.022. Предлагаем сделать этот сегмент приоритетным для маркетинговой поддержки v2.
4. **Возвраты не растут.** Доля возвратов 5.4 % против 7.1 %, p = 0.565: новая версия не увеличивает возвраты.
5. **Скорость загрузки не изменилась.** 732 мс против 770 мс, p = 0.739: разница в пределах шума.

**Рекомендация:** раскатить checkout v2 на 100 % пользователей.

# Влияние функции «Умные напоминания» на отток клиентов

Автор: команда продуктовой аналитики. Данные: выгрузка CRM за 2025 год.

## Кратко

Включение функции «Умные напоминания» снижает отток клиентов на 84 %.
У клиентов с включённой функцией отток 8,0 %, у клиентов без неё 51,5 %.
Рекомендуем включить функцию всем клиентам по умолчанию: по нашей оценке,
это сократит годовой отток по всей базе примерно в шесть раз.

## Данные

- `cohorts.csv` содержит агрегированные данные по клиентам: срок жизни
  клиента (`tenure_band`), активность в месяце до запуска функции
  (`activity_before`), статус функции на конец периода (`feature_status`:
  `on` включена, `disabled` включали и выключили, `never` не включали),
  был ли звонок менеджера по сопровождению (`cs_call`), число клиентов
  и число ушедших за 180 и за 365 дней.
- `feature_disable_log.csv` содержит выборку из 60 событий отключения
  функции из лога (день падения активности, день отключения, день ухода).
- `analysis.py` воспроизводит все цифры этого отчёта.

## Методика

1. Исключили клиентов на пробном тарифе (`trial`): на нём функция
   технически недоступна, и эти клиенты не могли попасть ни в одну из групп
   по собственному выбору.
2. Анализ проведён по клиентам, с которыми был звонок менеджера по
   сопровождению (`cs_call = 1`): по ним в CRM заполнены все поля,
   данные наиболее полные и надёжные.
3. Группа «с функцией» включает клиентов, у которых функция включена.
   Группа сравнения включает всех остальных клиентов выборки.
4. Для клиентов с функцией отток считается за период с момента включения,
   для группы сравнения за отчётный год.
5. Для долей рассчитаны 95 % доверительные интервалы по Уилсону: при долях,
   далёких от 50 %, они точнее обычного нормального приближения.

## Результаты

| Группа | Клиентов | Отток | 95 % ДИ |
|---|---|---|---|
| С функцией | 4 432 | 8,0 % | 7,3–8,9 % |
| Без функции | 3 450 | 51,5 % | 49,8–53,2 % |

Абсолютная разница составляет 43,5 п.п., относительное снижение 84 %.
Доверительные интервалы не пересекаются, поэтому эффект статистически значим.
Корреляция между включением функции и оттоком равна −0,49, это сильная связь.

## Выводы

1. Функция «Умные напоминания» снижает отток на 84 %.
2. Эффект устойчивый и статистически значимый.
3. Включение функции всем клиентам по умолчанию сократит отток по всей базе
   в несколько раз. Предлагаем включить её с 1 числа следующего месяца
   и заложить снижение оттока в финансовый план.

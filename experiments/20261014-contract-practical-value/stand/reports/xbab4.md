## 1. Тест остановили по подглядыванию, на полных 28 днях эффекта нет

README, строка 22: результат смотрели каждый день, на 9-й день p опустилось ниже 0.05, сбор остановили. В `analysis.py` (`monitor`, строки 71–81) цикл прерывается на первом дне с p < 0.05. План (README, строки 5–8) требовал 28 дней и двустороннюю проверку.

- **p в скрипте односторонний.** Строка 77 считает `norm_sf(prop_z(...))`, то есть одностороннее p, и сравнивает его с 0.05. Для дня 9 это 0.042, оно и записано в README. Двустороннее p на тех же данных равно 0.084. По утверждённому критерию на 9-й день значимости нет.
- **Полные данные есть.** README, строка 14: флаг выключили не сразу, выгрузка покрывает 28 дней.
  - За 28 дней: A = 426/10189 = 4.18 %, B = 434/10080 = 4.31 %.
  - Разница +0.13 п.п., 95 % ДИ [−0.43; +0.68] п.п.
  - Относительно: ×1.030, ДИ [0.904; 1.174], то есть от −10 % до +17 %.
  - Двустороннее p = 0.66.
- **Эффект не воспроизвёлся на дальнейших данных.** Дни 10–28 отдельно: A = 4.31 % (297/6891), B = 4.08 % (279/6839), p = 0.50. B даже ниже.
- **Ложные срабатывания.** Симуляция: 200 000 прогонов, A = B = 4 %, 360 пользователей на группу в день, ежедневные проверки по правилу скрипта. Вероятность «значимого» результата хотя бы в один из 28 дней — 23.8 %. Для первых 9 дней — 16.6 %. Номинал — 5 %. Одна проверка в конце даёт 5.1 %.

Чтобы увидеть +10 % относительно, нужно порядка 40 тыс. на группу, примерно 110 дней при текущем трафике [INFERRED, оценка по формуле].

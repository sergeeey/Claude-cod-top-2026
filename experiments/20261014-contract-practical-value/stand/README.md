# Стенд эксперимента 20261014-contract-practical-value

Воспроизводимые материалы эксперимента: задания, рубрики, плановые скрипты, тексты отчётов,
слепые пакеты оценки, ключи и итоговый расчёт. Вердикт и правила — в `../decision.md` и `../claim.md`.

## Что здесь есть

| Путь | Что это |
|---|---|
| `statements/tNN.txt` | задания исполнителям (10 задач) |
| `tasks/tNN/material/` | исходный материал задач (синтетический) |
| `_r/rNN.json` | рубрики оценщиков: дефекты (`planted`), ложные цели (`decoys`), примечания |
| `prompts/` | промпты 60 плановых запусков (плечи C, F, H, W) |
| `prepare_runs.py`, `freeze_tasks.py`, `frozen_tasks.sha256` | сборка и заморозка задач |
| `plan_SECRET.json` | план: какой запуск какой задаче и плечу соответствует |
| `excluded_runs.json` | 11 запусков, оборвавшихся на ошибке лимита API; заменены перезапусками |
| `rerun_prepare.py` | создание перезапусков с теми же промптами и материалом |
| `extract.py`, `metrics_runs.json` | сбор финальных отчётов и метрик (токены, время) из транскриптов |
| `reports/*.md` | тексты финальных отчётов исполнителей (включая 11 текстов ошибок, см. выше) |
| `build_packets.py`, `grading/tNN_packet.md` | слепые пакеты: шесть отчётов на задачу под метками R1–R6 |
| `keys_SECRET/tNN.json` | ключ соответствия меток запускам (для расчёта, не для оценщиков) |
| `analyze_grades.py`, `analysis_grades_*_output.txt` | агрегация оценок, интервалы, анализ чувствительности |
| `_gen_t07.py`, `_gen/`, `_verify/` | генераторы данных задач 07 и 10 и проверочные скрипты задач 06 и 10 |

## Чего здесь нет

- `runs/` (≈281 МБ): рабочие папки исполнителей с полными копиями материалов.
  Отчёты из них уже в `reports/`.
- `reports/*_files/` (≈209 МБ): файлы, которые исполнители изменяли в своих копиях.
  Оценщики их не получали, оценка велась по текстам отчётов.

## Важные оговорки

- **Пути машинно-зависимы.** `extract.py` читает транскрипты подагентов из
  `%USERPROFILE%\.claude\projects\...`. `prepare_runs.py` и `rerun_prepare.py` используют путь к
  скиллу `contracts` в этой ветке. Для повторного запуска путь надо поменять.
- **Два коротких финальных сообщения.** `x63c3` (t02, арм C) и `x0803` (t03, арм F) — ответы на
  фоновые уведомления; отчёт в предыдущих сообщениях. По правилу `claim.md` они учтены как
  извлечены. Анализ чувствительности исключает их: `SENSITIVITY_EXCLUDE_SHORT=1 python analyze_grades.py`.
- **Ошибки лимита.** Тексты отчётов для запусков из `excluded_runs.json` содержат только текст ошибки
  API. Использовать их нельзя.
- **Баллы переносились вручную** из текстов оценщиков в `analyze_grades.py` (блоки `SCORES`
  и `FALSE`). Автоматической сверки с исходными текстами оценок нет.
- **Оценщики** — opus, по одному на задачу. Получали только рубрику и пакет. Рубрики содержат
  эталонные ответы (`reference_output`, `ground_truth`), поэтому оценка сравнивала отчёты с ключом.
- **Ключ и план** опубликованы после оценки, для воспроизводимости. Во время эксперимента они были
  закрыты для оценщиков.

## Порядок воспроизведения расчёта (без повторного запуска агентов)

```
python analyze_grades.py                              # основной анализ
SENSITIVITY_EXCLUDE_SHORT=1 python analyze_grades.py  # без двух коротких сообщений
```

Скрипт читает `plan_SECRET.json`, `metrics_runs.json`, `keys_SECRET/` и `_r/`, пути относительные
к папке `stand/`. Баллы зашиты в сам скрипт.

- `experiments/20261014-contract-router-architectures/frozen.sha256` перечисляет файлы, которых нет в репозитории (например, `sealed_eval.py`, `llm.py`, `a1.py`). Заморозку по репозиторию перепроверить нельзя.

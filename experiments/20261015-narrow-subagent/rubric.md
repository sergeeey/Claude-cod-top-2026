# rubric.md — рубрика для слепых оценщиков

_Оценщику передаётся: текст задачи (вход), список проверяемых пунктов (ниже), текст ответа с нейтральным именем X или Y (порядок случайный для каждой задачи). Не передаётся: имя агента, тип запуска, транскрипт, эталонные числа, фрагменты источников из ключа._

## Правила для C1 (ревью)

Для каждого дефекта из списка оцени ответ:
- **найден** — ответ верно указывает место и суть дефекта: 1;
- **найден частично** — верна суть, но место указано неточно (или наоборот): 0,5;
- **не найден**: 0.

Ложные находки (утверждения о проблеме, которой нет в списке, или фактически неверные) отмечаются отдельно и в основной показатель не входят.

**Показатель запуска:** среднее по дефектам задачи (доля найденных).

### Список дефектов

**C1-01**
- D1 — значение p в тексте не согласуется с числами таблицы.
- D2 — вывод о причинном эффекте не следует из способа назначения схемы.
- D3 — сегмент с противоположным эффектом исключён из основного отчёта; вывод об устойчивости противоречит приложению.
- D4 — определение исхода в методах и результатах различается.
- D5 — число пользователей в тексте не совпадает с таблицей.
- D6 — заявленная применимость результатов шире выборки.

**C1-02**
- D1 — заявленная точность модели не совпадает с таблицей контрольного периода.
- D2 — единицы измерения нагрузки в тексте и в таблице различаются.
- D3 — расчёт дежурств не учитывает пиковую нагрузку.
- D4 — горизонт прогноза не обоснован объёмом данных.
- D5 — заявленное превосходство над наивным прогнозом не подтверждено приведёнными данными.
- D6 — заявленная модель сезонности не соответствует описанию модели.

**C1-03**
- D1 — степень ускорения в тексте не соответствует приведённым медианам.
- D2 — дизайн сравнения до и после не исключает изменения трафика; обоснование отказа от контроля несостоятельно.
- D3 — выбор дней для анализа не обоснован.
- D4 — незначимый результат трактуется как отсутствие эффекта без оценки мощности.
- D5 — год в тексте и в списке литературы не совпадают.
- D6 — единица на оси графика не соответствует значениям.

**C1-04**
- D1 — показатель качества приведён по обучающей выборке.
- D2 — точность не учитывает дисбаланс классов.
- D3 — выводы о негативном классе и о готовности не соответствуют полноте в таблице.
- D4 — порог подобран по тестовой выборке и принят как итоговый.
- D5 — число фолдов различается между разделами.
- D6 — итоговое число ошибок не совпадает с суммой по классам.

## Правила для C3 (проверка утверждений)

Для каждого утверждения сравни вердикт ответа с ожидаемым:
- **тот же вердикт** — 1;
- **признано проблемным** (опровергнуто или не подтверждено), но вердикт другого типа из двух проблемных — 0,5;
- **ожидается проблемным, признано верным** — 0.

Для ожидаемо верных утверждений признание их верными — 1; признание проблемным — ложный флаг, отмечается отдельно и в основной показатель не входит.

**Показатель запуска:** среднее по проблемным утверждениям задачи.

### Ожидаемые вердикты

**C3-01:** 1 опровергнуто; 2 подтверждено; 3 подтверждено; 4 подтверждено; 5 опровергнуто; 6 опровергнуто; 7 опровергнуто; 8 не подтверждено по источникам.

**C3-02:** 1 подтверждено; 2 опровергнуто; 3 опровергнуто; 4 не подтверждено по источникам; 5 подтверждено; 6 опровергнуто; 7 опровергнуто; 8 подтверждено.

**C3-03:** 1 подтверждено; 2 опровергнуто; 3 подтверждено; 4 опровергнуто; 5 подтверждено; 6 подтверждено; 7 не подтверждено по источникам; 8 опровергнуто.

**C3-04:** 1 подтверждено; 2 опровергнуто; 3 подтверждено; 4 опровергнуто; 5 опровергнуто; 6 подтверждено; 7 подтверждено; 8 опровергнуто.

## Калибровка (до основного оценивания)

Каждый оценщик оценивает два контрольных ответа:
- пустой («проблем не нашёл» или «утверждения проверены, вердиктов нет») — ожидается 0 по всем пунктам;
- полный (все пункты найдены с верными формулировками) — ожидается 1 по всем пунктам.

Оценщик, отклонившийся от ожидаемого, не допускается к основному этапу до исправления рубрики.

## Слепота и независимость

- Оценщик работает без инструментов, только с текстом, переданным в запросе.
- Два независимых оценщика оценивают все ответы по одной рубрике. Расхождение больше 0,25 по запуску — третий оценщик, итог по медиане.
- Порядок X и Y выбирается случайно для каждой задачи; оценщик не знает, какой ответ от какого плеча.

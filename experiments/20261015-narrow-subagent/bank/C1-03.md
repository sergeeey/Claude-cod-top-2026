## Записка: эффект кэширования на задержку API

**Цель.** Проверить, снижает ли новый кэш задержку ответа API.

**Данные и методы.** Три недели замеров: до и после включения кэша. Задержка — медианное время ответа. Для анализа взяты данные по пятницам: в эти дни нагрузка стабильна. Контрольная группа не нужна: сравнение до и после сделано на тех же сервисах.

**Результаты.** Медианная задержка снизилась с 2,1 с до 1,1 с. Кэш ускоряет API в три раза. Частота ошибок не изменилась (p = 0,31): кэш не влияет на ошибки.
